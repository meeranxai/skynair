# About Section - اردو گائیڈ ✅

## خلاصہ
Settings میں خوبصورت "About" سیکشن شامل کیا گیا ہے جس میں G-NETWORK کی معلومات اور WhatsApp کمیونٹی کا لنک ہے۔

## کیا تبدیلیاں کی گئیں؟

### 1. خوبصورت About ڈائیلاگ
- **جدید ڈیزائن**: گول کونوں والا خوبصورت ڈائیلاگ
- **ایپ آئیکن**: گول آئیکن پرائمری رنگ میں
- **ورژن نمبر**: موجودہ ایپ ورژن دکھاتا ہے
- **G-NETWORK معلومات**: پلیٹ فارم کی مکمل تفصیل
- **WhatsApp کمیونٹی**: کمیونٹی میں شامل ہونے کا براہ راست لنک

### 2. WhatsApp کمیونٹی انٹیگریشن
- **سبز گریڈینٹ بٹن**: WhatsApp تھیم والا دلکش بٹن
- **براہ راست لنک**: WhatsApp کمیونٹی چینل کھولتا ہے
- **خرابی کی ہینڈلنگ**: اگر لنک نہ کھلے تو پیغام دکھاتا ہے
- **بیرونی لانچ**: WhatsApp ایپ یا براؤزر میں کھولتا ہے

## تبدیل شدہ فائلیں

### `lib/features/settings/pages/settings_page.dart`
- `url_launcher` امپورٹ شامل کیا
- ڈیفالٹ `showAboutDialog` کو کسٹم ڈائیلاگ سے بدلا
- `_launchWhatsAppCommunity()` میتھڈ شامل کیا
- گریڈینٹ بٹن کے ساتھ خوبصورت UI

### `pubspec.yaml`
- `url_launcher: ^6.3.1` پیکیج شامل کیا

## خصوصیات

### About ڈائیلاگ کا مواد

#### 1. ہیڈر سیکشن
- 🎨 گول ایپ آئیکن پرائمری رنگ میں
- 📱 "G-NETWORK" ٹائٹل بولڈ میں
- 🔢 ورژن نمبر ڈسپلے

#### 2. معلومات کا سیکشن
```
About G-NETWORK

G-NETWORK ایک سوشل پلیٹ فارم ہے جہاں یوزرز پوسٹس اور 
تصاویر شیئر کر سکتے ہیں، لائک، کمنٹ، مواد محفوظ کر 
سکتے ہیں، اور دوسرے یوزرز کو فالو کر سکتے ہیں۔ 
Phase One بنیادی خصوصیات پر توجہ مرکوز کرتا ہے تاکہ 
شیئرنگ اور ایکسپلورنگ آسان ہو۔
```

#### 3. WhatsApp کمیونٹی بٹن
- 💚 سبز گریڈینٹ بیک گراؤنڈ (WhatsApp رنگ)
- 💬 چیٹ ببل آئیکن
- 📝 "Join Our Community" ٹیکسٹ
- ➡️ ایکشن کے لیے تیر کا آئیکن
- ✨ گہرائی کے لیے سایہ اثر

#### 4. بند کرنے کا بٹن
- ڈائیلاگ بند کرنے کے لیے سادہ ٹیکسٹ بٹن

## ٹیسٹنگ

### ٹیسٹ فائل چلائیں
```bash
test_about_section.bat
```

### دستی ٹیسٹنگ کے مراحل

1. **Settings کھولیں**
   - Profile ٹیب پر جائیں
   - Settings آئیکن کلک کریں (اوپر دائیں)

2. **About پر جائیں**
   - "Support" سیکشن تک سکرول کریں
   - "About" آپشن پر کلک کریں
   - سب ٹائٹل میں ورژن نمبر دکھائی دے گا

3. **About ڈائیلاگ دیکھیں**
   - خوبصورت گول ڈائیلاگ ظاہر ہوتا ہے
   - G-NETWORK آئیکن اور ٹائٹل دیکھیں
   - ایپ کی تفصیل پڑھیں
   - WhatsApp کمیونٹی بٹن دیکھیں

4. **WhatsApp لنک ٹیسٹ کریں**
   - "Join Our Community" بٹن کلک کریں
   - WhatsApp ایپ کھلنی چاہیے
   - G-NETWORK کمیونٹی چینل پر جائیں
   - اگر WhatsApp انسٹال نہیں تو براؤزر میں کھلے گا

5. **ڈائیلاگ بند کریں**
   - "Close" بٹن کلک کریں
   - ڈائیلاگ آسانی سے بند ہو جاتا ہے
