╔════════════════════════════════════════════════════════════════╗
║                    IMPORTANT NOTES                             ║
╚════════════════════════════════════════════════════════════════╝

📌 APK Files Location:
   build/app/outputs/flutter-apk/

📌 Recommended Upload:
   - Upload all split APKs (armeabi-v7a, arm64-v8a, x86_64)
   - OR upload universal APK (larger size)

📌 Privacy Policy & Terms:
   - Must be hosted online (not just in app)
   - Use GitHub Pages, Firebase Hosting, or your website
   - URLs must be accessible without login

📌 Screenshots Tips:
   - Use real content (not lorem ipsum)
   - Show app's best features
   - Clean, professional look
   - No personal information visible
   - Consistent device frame (optional)

📌 Description Tips:
   - Highlight unique features
   - Use bullet points
   - Keep it concise
   - Include keywords naturally
   - Mention "no ads" if true

📌 Common Rejection Reasons:
   ✗ Low-quality screenshots
   ✗ Missing privacy policy
   ✗ Misleading description
   ✗ App crashes on launch
   ✗ Inappropriate content
   ✗ Copyright violations

📌 Approval Timeline:
   - Initial review: 24-48 hours
   - Updates: 12-24 hours
   - Rejections: Fix and resubmit

📌 After Approval:
   - Share APKPure link
   - Promote on social media
   - Collect user reviews
   - Plan regular updates
   - Monitor crash reports

║                    QUICK COMMANDS                              ║
╚════════════════════════════════════════════════════════════════╝

Build APK:
> prepare_apkpure_release.bat

Test on device:
> adb install build\app\outputs\flutter-apk\app-release.apk

Check APK size:
> dir build\app\outputs\flutter-apk\

View app info:
> flutter pub run flutter_launcher_icons:main
