## 🔧 Build Instructions

### Quick Build:
```bash
prepare_apkpure_release.bat
```

### Manual Build:
```bash
flutter clean
flutter pub get
flutter build apk --release --split-per-abi
```

### APK Location:
```
build/app/outputs/flutter-apk/
├── app-armeabi-v7a-release.apk (~25MB)
├── app-arm64-v8a-release.apk (~28MB)
└── app-x86_64-release.apk (~30MB)
```
