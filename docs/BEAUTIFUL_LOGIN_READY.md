## 🔥 **To Connect Firebase (5 minutes)**

### **Quick Steps:**
1. **Go to**: https://console.firebase.google.com/
2. **Create project**: "g-network-flutter"
3. **Add web app**: Get configuration
4. **Update**: `lib/firebase_options.dart` with your config
5. **Enable**: Google authentication in Firebase Console
6. **Test**: Google Sign-In button will work!
