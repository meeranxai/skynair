## 🔧 **Troubleshooting**

### **Can't Access on Phone?**
1. **Check WiFi**: Both devices on same network?
2. **Try URL**: `http://192.168.1.6:8080`
3. **Firewall**: Windows firewall might block port 8080
4. **Browser**: Try different browser (Chrome recommended)

### **App Not Loading?**
1. **Wait**: Initial load takes 30-60 seconds
2. **Refresh**: Reload the page
3. **Clear Cache**: Clear browser cache
4. **Check Console**: Look for error messages

### **Features Not Working?**
1. **Internet**: Check internet connection
2. **Backend**: Some features need your G-Network server running
3. **Firebase**: Authentication might need proper Firebase config
