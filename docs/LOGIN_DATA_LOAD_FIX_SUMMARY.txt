✅ LOGIN DATA LOAD FIX - COMPLETE
=====================================

PROBLEM:
--------
- Jab naye login karte the to Firebase se data nahi dikhta tha
- Posts load nahi hote the
- App ko restart karna padta tha

ROOT CAUSE:
-----------
1. Race condition between auth completion and router redirect
2. Posts provider wasn't listening to auth state changes
3. Home page wasn't detecting when user logged in

SOLUTION:
---------

1. LOGIN PAGE (lib/features/auth/pages/login_page.dart)
   - Added explicit navigation to /home after successful login
   - Ensures home page is mounted and can load data

2. ROUTER (lib/core/router/router_provider.dart)
   - Added isLoading check to prevent redirects during auth
   - Prevents race conditions

3. POSTS PROVIDER (lib/core/providers/posts_provider.dart)
   - Added listener for auth state changes (user?.uid)
   - Automatically fetches posts when user logs in
   - Clears posts when user logs out
   - Added clearPosts() method

4. HOME PAGE (lib/features/home/pages/home_page.dart)
   - Added didChangeDependencies() to detect auth changes
   - Checks if posts are empty and refetches if needed
   - Only loads data when user is authenticated
