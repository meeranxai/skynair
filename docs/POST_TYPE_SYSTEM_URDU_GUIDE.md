# Post Type System - Urdu Guide 🇵🇰 (Updated)

## Sahi Rules ✅

### 1. Media Post 📷
- **Picture ZARURI hai** (Must have)
- Text optional hai (chahiye toh likho, nahi toh mat likho)
- Home feed mein show hoga
- Sirf picture bhi post kar sakte ho!

### 2. Article 📝
- **Text ZARURI hai** (Must have)
- Picture optional hai (chahiye toh add karo, nahi toh mat karo)
- Articles tab mein show hoga
- Long articles ke liye perfect

## Kya Badla Hai? 

### 1. Plus Icon Par Click Karo
Jab aap plus (+) icon par click karoge, ab 2 options milenge:

#### Option 1: Media Post 📷
- **Picture ZARURI hai**
- Text optional hai
- Bina picture ke post nahi ban sakti
- Agar picture nahi add ki, toh error aayega: "Media post requires an image"
- Home feed mein dikhega

#### Option 2: Article 📝
- **Text ZARURI hai**
- Picture optional hai (add kar sakte ho agar chahiye)
- Long-form content ke liye perfect
- Articles tab mein dikhega

### 2. Bottom Navigation Badal Gaya
**Pehle:**
```
Home | Explore | + | Notifications | Profile
```

**Ab:**
```
Home | Explore | + | Articles | Profile
```

- Notification ko Articles se replace kar diya
- Articles mein sirf article-type posts dikhenge

### 3. Top Mein Notification Shift Ho Gaya
Ab **Home**, **Explore**, aur **Articles** pages ke top par:
- 🔔 Notification icon
- 💬 Messages icon

Dono icons top right corner mein honge.

### 4. Feed Filtering
- **Home Feed**: Sirf media posts (jo picture ke saath hain)
- **Articles Tab**: Sirf articles (jo text-based hain)

## Kaise Use Karein?

### Media Post Banana (Picture Zaruri):
1. Plus (+) icon par click karo
2. "Media Post" select karo
3. Title likho (optional)
4. Description likho (optional)
5. **Picture add karo** (ZARURI!)
6. Category select karo
7. "Post" button dabao
8. Post home feed mein dikhega

**Note:** Agar picture nahi add ki, toh error aayega!

**Examples:**
- Sirf picture post kar sakte ho (no text needed)
- Picture + title
- Picture + title + description

### Article Likhna (Text Zaruri):
1. Plus (+) icon par click karo
2. "Article" select karo
3. Title likho
4. **Description likho** (ZARURI!)
5. Picture add karo (optional - chahiye toh karo)
6. Category select karo
7. "Post" button dabao
8. Article articles tab mein dikhega

**Note:** Text zaruri hai, picture optional!

**Examples:**
- Sirf text article (no picture)
- Text + picture article
- Long blog-style posts

### Articles Dekhna:
1. Bottom navigation mein "Articles" par click karo
2. Sirf article-type posts dikhenge
3. Floating button se naya article likh sakte ho

### Notifications Dekhna:
1. Kisi bhi page ke top par bell icon (🔔) par click karo
2. Notifications page khul jayega

### Messages Dekhna:
1. Kisi bhi page ke top par message icon (💬) par click karo
2. Messages list khul jayegi

## Common Questions

### Q: Kya media post mein text zaruri hai?
**A:** Nahi! Media post mein sirf picture zaruri hai. Text optional hai. Sirf picture bhi post kar sakte ho.

### Q: Kya article mein picture add kar sakte hain?
**A:** Haan! Article mein picture optional hai. Chahiye toh add karo, nahi toh mat karo. Lekin text zaruri hai.

### Q: Media post aur article mein kya fark hai?
**A:** 
- **Media Post**: Picture zaruri, text optional → Home feed
- **Article**: Text zaruri, picture optional → Articles tab

### Q: Notifications kahan gaye?
**A:** Notifications ab top bar mein hain (bell icon 🔔). Har page se access kar sakte ho.

### Q: Purane posts ka kya hoga?
**A:** Purane posts automatically media posts ban jayenge (backward compatibility).

### Q: Kya existing post ko edit kar sakte hain?
**A:** Haan, lekin post type nahi badal sakta. Media post media hi rahega, article article hi rahega.

## Troubleshooting

### Problem: Media post submit nahi ho rahi
**Solution:** Check karo ke picture add ki hai ya nahi. Picture zaruri hai!

### Problem: Article submit nahi ho rahi
**Solution:** Check karo ke description likhi hai ya nahi. Text zaruri hai!

### Problem: Notification icon nahi dikh raha
**Solution:** Top right corner mein dekho. Bell icon (🔔) hona chahiye.

### Problem: Articles page khali hai
**Solution:** Abhi tak koi article post nahi hai. Naya article likho!

### Problem: Home feed mein articles dikh rahe hain
**Solution:** Yeh nahi hona chahiye. Sirf media posts dikhne chahiye. App restart karo.
