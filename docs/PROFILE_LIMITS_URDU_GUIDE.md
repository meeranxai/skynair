# پروفائل ایڈٹ لمٹس - مکمل گائیڈ ✅

## کیا تبدیلیاں کی گئیں؟

### 1. یوزرنیم کی حد: 30 حروف
- یوزرنیم فیلڈ میں زیادہ سے زیادہ 30 حروف لکھ سکتے ہیں
- اگر 30 سے زیادہ لکھیں گے تو خرابی کا پیغام آئے گا
- نیچے حروف کا کاؤنٹر دکھائی دیتا ہے (مثال: 15/30)

### 2. ڈسپلے نیم کی حد: 30 حروف
- ڈسپلے نیم میں بھی زیادہ سے زیادہ 30 حروف
- اگر 30 سے زیادہ لکھیں گے تو سرخ پیغام آئے گا
- نیچے حروف کا کاؤنٹر دکھائی دیتا ہے

### 3. ڈسپلے نیم تبدیل کرنے کی حد: 14 دنوں میں 2 بار
- آپ 14 دنوں میں صرف 2 بار ڈسپلے نیم تبدیل کر سکتے ہیں
- تیسری بار کوشش کریں گے تو خوبصورت وارننگ ڈائیلاگ آئے گا
- ڈائیلاگ میں بتائے گا کہ کتنے دن بعد دوبارہ تبدیل کر سکتے ہیں

### 4. وارننگ پیغامات
- **یوزرنیم بہت لمبا**: فیلڈ کے نیچے سرخ ٹیکسٹ
- **ڈسپلے نیم بہت لمبا**: نیچے سرخ سنیک بار
- **ڈسپلے نیم لمٹ ختم**: خوبصورت ڈائیلاگ باکس

## ٹیسٹنگ کیسے کریں؟

### طریقہ 1: بیٹ فائل چلائیں
```bash
test_profile_limits.bat
```

### طریقہ 2: ایپ چلا کر ٹیسٹ کریں

1. **یوزرنیم ٹیسٹ**
   - پروفائل پر جائیں
   - Edit Profile بٹن دبائیں
   - یوزرنیم میں 30 سے زیادہ حروف لکھنے کی کوشش کریں
   - دیکھیں: "Username cannot exceed 30 characters"

2. **ڈسپلے نیم ٹیسٹ**
   - ڈسپلے نیم میں 30 سے زیادہ حروف لکھیں
   - Save بٹن دبائیں
   - دیکھیں: "Display name cannot exceed 30 characters"

3. **ڈسپلے نیم چینج لمٹ ٹیسٹ**
   - پہلی بار ڈسپلے نیم تبدیل کریں → کامیاب
   - دوسری بار تبدیل کریں → کامیاب
   - تیسری بار کوشش کریں → وارننگ ڈائیلاگ آئے گا
   - ڈائیلاگ میں دیکھیں کتنے دن باقی ہیں

## وارننگ ڈائیلاگ کی خصوصیات

### ڈیزائن
- ⚠️ وارننگ آئیکن (سرخ رنگ)
- 🎨 خوبصورت گول ڈیزائن
- 📦 ہائی لائٹ شدہ انفو باکس

### پیغامات
```
آپ نے 14 دنوں میں 2 بار Display Name تبدیل کر لیا ہے۔

You have already changed your display name 2 times 
in the last 14 days.

⏰ آپ X دن بعد دوبارہ تبدیل کر سکتے ہیں
   You can change it again in X days.
```

## فوائد

### 1. ڈیٹا بیس کی حفاظت
- بہت لمبے ناموں سے بچاؤ
- ڈیٹا بیس میں جگہ کی بچت

### 2. بہتر یوزر انٹرفیس
- نام UI میں صحیح طریقے سے فٹ ہوتے ہیں
- کوئی ٹیکسٹ باہر نہیں نکلتا

### 3. سپیم سے بچاؤ
- لوگ بار بار نام نہیں بدل سکتے
- پروفیشنل ماحول برقرار رہتا ہے

### 4. واضح فیڈبیک
- یوزر کو فوری پتہ چل جاتا ہے کیا غلطی ہے
- سمجھنے میں آسان پیغامات

## تکنیکی تفصیلات

### یوزرنیم کی جانچ
```
1. خالی یا پرانا ہے؟ → اجازت
2. 3 سے کم حروف؟ → خرابی
3. 30 سے زیادہ حروف؟ → خرابی (نیا)
4. غلط حروف؟ → خرابی
5. پہلے سے موجود؟ → خرابی
```

### ڈسپلے نیم کی جانچ
```
1. خالی ہے؟ → خرابی
2. 30 سے زیادہ حروف؟ → خرابی (نیا)
3. 14 دنوں میں 2 بار تبدیل؟ → وارننگ
4. سب ٹھیک؟ → محفوظ کریں
```

### ڈیٹا بیس فیلڈز
```dart
{
  'displayName': String,           // ڈسپلے نیم
  'username': String,              // یوزرنیم
  'lastDisplayNameChange': Timestamp,  // آخری تبدیلی کا وقت
  'displayNameChangeCount': int,   // تبدیلیوں کی تعداد
}
```
